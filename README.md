# Portfólio José Caldas

Portfólio pessoal responsivo em HTML, CSS e JavaScript.

## Arquivos

- `index.html`: apresentação, habilidades, formação e contato.
- `projetos.html`: os nove projetos públicos com capturas reais e links.
- `styles.css`: estilos das duas páginas e ajustes para celular.
- `script.js`: animação 3D e diálogo de contato da página inicial.
- `assets/`: capturas das aplicações e repositórios.

## Executar

Abra a pasta no VS Code e use a extensão Live Server para abrir `index.html`.

## Atualizar no GitHub e Vercel

Substitua os arquivos antigos, incluindo `projetos.html` e a pasta `assets`, faça commit e push. O Vercel deve publicar o novo commit quando estiver conectado ao repositório.

## Imagens

Capturas reais das aplicações e repositórios. O print do Nexo está disponível no próprio repositório. Os cards Python identificam capturas do repositório.

## Organização

HTML, CSS e JavaScript formatados com indentação e múltiplas linhas.
